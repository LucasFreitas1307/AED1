#  Algoritmos e Estruturas de Dados

Repositório destinado ao armazenamento dos códigos e projetos desenvolvidos durante a disciplina de **Algoritmos e Estruturas de Dados** do curso de **Ciência da Computação** da **Universidade Federal de Goiás (UFG)**.

---

##  Conteúdos Abordados

Durante a disciplina, os seguintes conceitos foram estudados e implementados:

*   **Alocação Dinâmica de Memória:**
    *   Filas (*Queues*)
    *   Pilhas (*Stacks*)
    *   Listas (*Linked Lists*)
*   **Estruturas de Dados Não-lineares:**
    *   Árvores, Grafos e outras estruturas complexas.

##  Tecnologias Utilizadas

*   **Linguagem de Programação:** C

---

> **Nota:** Todos os códigos presentes neste repositório foram criados com fins puramente acadêmicos para consolidar o aprendizado em estruturas de dados clássicas.
